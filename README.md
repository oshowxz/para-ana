# ❤️ Para a Ana

Um site interativo feito com carinho para guardar memórias, momentos e sentimentos em um só lugar.

## Páginas
* **Home:** mensagem de boas-vindas.
* **For You:** carta de aniversário.
* **Our Day:** o nosso dia e as nossas promessas.
* **Memories:** timeline de fotos e player de música.

## Estrutura de pastas
```
index.html  foryou.html  ourday.html  memories.html
style.css   script.js
favicon/            coracao.png
fonts/              Gilda Display
music/              music01.mp3, music02.mp3
fotos-projeto/      foto01.jpg ... foto10.jpeg (adicione as suas)
background/         imagens dos lírios
```

## Tecnologias
HTML5, CSS3, JavaScript puro e GitHub Pages.

## Publicar no GitHub Pages
1. Envie todos os arquivos para o repositório.
2. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
